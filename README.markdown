# Приложение для визуализации данных ЭМГ

Это веб-приложение на основе Flask, предназначенное для загрузки, хранения, визуализации и анализа наборов данных электромиографии (ЭМГ). Приложение позволяет пользователям загружать файлы Excel с данными ЭМГ, просматривать статистические сводки, визуализировать данные с помощью интерактивных графиков и вычислять специфические метрики, такие как количество пиков в данных угла.

## Возможности

- **Загрузка наборов данных**: Загрузка файлов Excel (.xlsx) с данными ЭМГ, содержащих столбцы `timestamp`, `emg1`, `emg2`, `emg3`, `emg4` и `angle`.
- **Хранение данных**: Сохранение наборов данных в базе SQLite для постоянного доступа.
- **Визуализация**: Отображение интерактивных линейных графиков сигналов ЭМГ и угла с использованием Chart.js.
- **Статистика**: Вычисление и отображение средних и максимальных значений для каждого столбца данных.
- **Обнаружение пиков**: Подсчет количества пиков в столбце `angle`, где значение превышает предыдущий минимум на 20 единиц.
- **REST API**: Обновление наборов данных через запрос `PUT` на эндпоинт `/api/dataset/<id>`.
- **Обработка ошибок**: Валидация загружаемых файлов и обработка ошибок с понятными сообщениями для пользователя.

## Требования

- Python 3.8+
- Flask
- Pandas
- Openpyxl
- SQLite3

## Установка

1. Склонируйте репозиторий:

   ```bash
   git clone <https://github.com/nikita-szr/data_worker_flask/tree/feature_1>
   cd project
   ```

2. Создайте виртуальное окружение и активируйте его:

   ```bash
   python -m venv venv
   source venv/bin/activate  # На Windows: venv\Scripts\activate
   ```

3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Создайте папку для загружаемых файлов:

   ```bash
   mkdir uploads
   ```

## Запуск приложения

1. Запустите сервер Flask:

   ```bash
   python app.py
   ```

2. Откройте веб-браузер и перейдите по адресу:

   ```
   http://localhost:5000
   ```

## Использование

1. **Главная страница** (`/`):

   - Отображает список всех доступных наборов данных.
   - Содержит ссылку для загрузки нового набора данных.

2. **Загрузка набора данных** (`/add_dataset`):

   - Укажите название набора данных и выберите файл Excel (.xlsx).
   - Файл должен содержать столбцы: `timestamp`, `emg1`, `emg2`, `emg3`, `emg4`, `angle` с числовыми значениями.
   - После загрузки вы будете перенаправлены на страницу визуализации набора данных.

3. **Просмотр набора данных** (`/dataset/<id>`):

   - Отображает статистические сводки (средние, максимумы, количество пиков).
   - Показывает интерактивные линейные графики для сигналов ЭМГ и угла.
   - Позволяет обновить набор данных, загрузив новый файл.

4. **Обновление набора данных через API**:

   - Отправьте запрос `PUT` на `/api/dataset/<id>` с телом `multipart/form-data`, содержащим:

     - `file`: Новый файл .xlsx.
     - `dataset_name`: Опциональное новое название набора данных.

   - Пример с использованием `curl`:

     ```bash
     curl -X PUT -F "file=@corrected_data.xlsx" -F "dataset_name=Test" http://localhost:5000/api/dataset/1
     ```

## Формат файла Excel

Файл Excel должен иметь следующую структуру:

| timestamp | emg1 | emg2 | emg3 | emg4 | angle |
| --- | --- | --- | --- | --- | --- |
| 0 | \-136 | \-101 | 187 | \-156 | 32 |
| 14 | \-174 | \-143 | \-239 | \-149 | 32 |
| ... | ... | ... | ... | ... | ... |

Все значения должны быть числовыми. Нечисловые значения вызовут ошибку при загрузке.


## Примечания для разработчиков

- **Логирование**: Приложение записывает ошибки и ключевые события в консоль для отладки.
- **Ограничение размера файла**: Загрузка ограничена 16 МБ. При необходимости измените `MAX_CONTENT_LENGTH` в `app.py`.
- **Возможные улучшения**:
  - Добавить пагинацию для больших наборов данных.
  - Реализовать аутентификацию пользователей для ограничения доступа.
  - Поддержать дополнительные форматы файлов (например, CSV).
